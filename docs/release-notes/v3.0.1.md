Bug fix release for the native Linux mode.

## Fixes

- **Login failed in native Linux mode after unpacking as root**
  (`sandbox-exec: Permission denied (os error 13)`, `login failed (exit
  status: 127)`). The v3.0.0 archives kept the build machine's uid 1001 on
  `rootfs/`, and the rootless sandbox could not write there even as root.
  - Release archives are now owned by uid 0, so unpacking as root gives
    root-owned files; other users get their own uid as before.
  - Running as root with a rootfs the user namespace cannot write to (for
    example an existing v3.0.0 install), the agent logs a warning and uses
    the privileged sandbox instead.
  - As non-root, the agent refuses to start and prints the `chown` command
    to run, instead of failing on every login.
  - Sandbox setup errors now name the path that failed.

## Upgrading

Replace the `wrapper` binary; `rootfs/data` (accounts and settings) is kept.
To keep using the rootless sandbox on an existing install unpacked as root,
run `chown -R root:root rootfs`.
