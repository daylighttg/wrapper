First official release of the Rust rewrite: one `wrapper` binary with a web
panel that runs any number of Apple Music accounts behind a single
wrapper-lite compatible endpoint.

## Highlights

- **Multi-account agent.** Requests to `/m3u8`, `/key`, `/lyrics`,
  `/webplayback` and `/license` are routed to an account whose storefront can
  serve the item; account-specific failures are retried on another account.
- **wrapper-manager compatible.** `POST /login` (with 2FA) and `POST /logout`,
  so AppleMusicDecrypt and other clients work unchanged.
- **Web panel** (`wrapper` / `wrapper gui`): start/stop, accounts with
  interactive 2FA, settings, logs and per-account key health.
- **Runs everywhere.** `lite` runs in a small QEMU guest on Windows, macOS,
  Linux and Android, or natively on Linux x86_64 in a rootless user-namespace
  sandbox. Docker image for the native mode.
- **Android app.** Foreground service with the bundled QEMU and the same panel.
- **Health checks.** `/health` reports whether each account can really deliver
  a key (`?probe=1` probes live); unhealthy instances are restarted
  automatically.

## Upgrading

An existing single-account `qemu/data.img` (or `rootfs/data`) keeps working;
its account is migrated automatically and shows up as `legacy-account`.
