Adds `wrapper update`: upgrade an install from GitHub releases.

## New

- **`wrapper update`** checks the latest release, shows what changes and
  installs it. Only the parts that changed are downloaded: the `wrapper`
  binary, the QEMU guest (kernel + initramfs, which contains the agent),
  QEMU itself and the native rootfs. Parts you did not install are never
  added; `qemu/data.img`, `rootfs/data/` and panel settings are never touched.
  - `--check` only shows what would change, `-y` skips the question,
    `--version v3.0.2` installs a specific release (also older ones),
    `--only bin,guest` limits the update, `--mirror` downloads through
    gh-proxy.com.
  - Every file is checked against the release manifest, unpacked and tested
    before anything is replaced; a failed update leaves the install as it was.
  - Stop the panel / agent / QEMU before updating; on Linux the updater
    refuses while they run from the install directory.
- The panel checks for new releases at start-up and shows "vX available"
  under the version. Set `WRAPPER_NO_UPDATE_CHECK=1` to turn it off.
- Releases now also publish the components separately
  (`wrapper-<platform>[.exe]`, `guest.tar.gz`, `qemu-<platform>.tar.gz`,
  `rootfs-<platform>.tar.gz`) and `manifest.json`. See `docs/UPDATING.md`.

## Upgrading

This is the first release with `wrapper update`, so install it by hand once:
download the package and replace the `wrapper` binary and `qemu/` guest
files (`rootfs/data` and `qemu/data.img` keep your accounts). Later releases
are one `wrapper update` away.

The Android APK and Docker image are updated as before (new APK / new image).
